# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| latest `0.x` release | ✅ |
| older | ❌ |

## Reporting a vulnerability

Use GitHub's **private vulnerability reporting** (Security → Report a vulnerability) on the
repository. Do not open a public issue. Replace this section with a security contact email
and PGP key before the first public release.

We aim to acknowledge reports within 3 business days and to provide a fix or mitigation
plan within 90 days. Reporters are credited unless they prefer otherwise.

## Scope

The daemon, IPC protocol, rename engine, module runtime and packaging files. See the
[threat model](docs/THREAT_MODEL.md).
